# 1. Introduction

## 1.1 Purpose

This document defines the complete visual, interaction, layout, and component design system for the PixelForge portfolio website. The design is inspired by the **Milady Pixel Art Website**, which demonstrates a modern pixel-art interface combining retro aesthetics with clean, structured UI panels and professional usability. ([Dribbble][1])

The goal is to create a visually immersive pixel-art portfolio that presents Vinayak Tiwari as a modern, creative, and technically skilled developer.

---

# 2. Design Reference Analysis (Milady Pixel Art Website)

## 2.1 Key Visual Characteristics

The reference design uses:

* Pixel-art environment
* Character-centered layout

* Clean information hierarchy
