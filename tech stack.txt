Here is a **recommended tech stack** for your **Pixel Art Interactive Personal Portfolio Website**, optimized for **performance, pixel-perfect visuals, animations, and recruiter-level quality**, and aligned with your existing experience in **Next.js, Tailwind, and MongoDB**.

# Tech Stack – PixelForge Portfolio

## 1. Frontend Core (Primary Stack)

### Framework: Next.js 14+

**Why:**

* Industry standard for modern portfolios
* Server-side rendering (SSR) → better performance & SEO
* Built-in routing
* Optimized images and fonts
* Perfect for Vercel deployment

**Use for:**

* Full website structure
* Routing
* Layout system
* SEO optimization

---

### Library: React 18+

**Why:**

* Component-based architecture
* Reusable UI components
* Excellent ecosystem

**Use for:**

* UI components
* State management
* Interactive elements

---

### Styling: Tailwind CSS

**Why:**

* Fast development
* Easy responsive design
* Perfect for custom pixel themes
* Works well with Next.js

**Use for:**

* Layout styling
* Pixel UI styling
* Responsive design

---

### Pixel Styling: Custom Pixel Theme (CSS)

**Why:**

* Tailwind alone isn’t enough for pixel borders and effects

**Use for:**

* Pixel borders
* Pixel shadows
* Retro effects

---

# 2. Animation Stack
